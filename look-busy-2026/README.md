# Look Busy 2026 · 赛博让你看起来很忙

> **2026 年最后的体面：纯 H5 写了个「赛博让你看起来很忙」，老板路过以为我在炼大模型**

一个**零依赖、零构建、纯 H5** 的全屏伪装页。打开后你的屏幕会变成一个**"AI 大模型训练监控面板"**：
左边一片 Matrix 字符雨在下落、中间是滚动不停的 PyTorch 风格日志、右边是缓慢收敛的 loss 曲线和 4 张 A100 显存监控。

老板路过的时候，你只要按一下 <kbd>`</kbd>（反引号），整个屏幕**瞬间切回一个白底黑字的"公司内部技术文档"页面**，看起来你正在认真做架构调研。老板走了，再按一下，训练继续——loss 还在下降，毫无破绽。

## 主要功能

- 🟢 **假训练日志**：基于 30+ 条 PyTorch / HuggingFace 真实风格模板生成，`loss` 用 `0.85 * exp(-step/9000) + sin抖动 + 噪声` 缓慢收敛，专业人士都不容易看出来
- 📈 **假 loss/acc 曲线**（SVG）：双线、滚动窗口 200 点，自带网格和带阴影的"wandb"配色
- 💧 **Matrix 字符雨**：字符集混入"训练 / 损失 / 收敛 / 梯度 / 玄学"和 emoji，让"我看不懂代码"五个字写在每个路过者脸上
- 🖥️ **多卡 GPU 监控**：4 张 A100 80G，显存使用率在 78%-96% 范围内 ±50MB 抖动，越看越像真的
- ⌨️ **机械键盘音**（Web Audio 合成）：每生成一行日志触发一次，零素材、零文件，听起来你在猛敲代码
- 🚨 **老板键**：按 <kbd>`</kbd> 切换严肃文档页 / 按 <kbd>Esc</kbd> 直接逃 / 鼠标蹭到屏幕右上角也会触发（手忙脚乱也能切）
- 🖤 **CRT 扫描线滤镜 + 黑底绿字**：极客感拉满，让你看起来像在做生死攸关的事
- 🎨 **完全前端，零依赖**：没有 React、没有 Vue、没有 TypeScript、没有 npm install，双击 HTML 就能跑

## 一键运行

### 方式 1：双击就好（最快）

直接双击 `index.html`，用 Chrome / Edge 打开即可。

### 方式 2：静态服务（更稳）

```bash
cd look-busy-2026

# 任选其一
python -m http.server 8000
# 或：npx serve .
# 或：php -S 0.0.0.0:8000
```

然后浏览器访问 <http://localhost:8000>。

## 快捷键

| 按键 | 行为 |
|------|------|
| <kbd>`</kbd> (反引号) | 老板键：训练面板 / 严肃文档页 来回切 |
| <kbd>Esc</kbd> | 一键逃到严肃文档页（不切回） |
| 鼠标移到屏幕**右上角 50px** | 触发"避险"，切到文档页 |
| 在文档页**双击页面** | 切回训练面板 |
| 右下角 🔇 按钮 | 开/关键盘音 |

> 首次点击或按键后自动允许声音（浏览器 autoplay 策略限制，没法一开页就响）。

## 浏览器兼容性

- ✅ Chrome / Edge 89+
- ✅ Firefox 90+
- ⚠️ Safari 14+ 大致能用，扫描线 mix-blend-mode 在部分版本上效果偏弱
- ❌ IE / 古早浏览器不予支持（2026 年了，告辞）

## 性能

- 单页常驻 CPU 占用约 1-3%（取决于刷新率）
- 字符雨用 `requestAnimationFrame`，自动跟随显示器刷新率
- 日志 DOM 自动裁剪到 200 行以内，不会内存爆炸
- 想再省点：把 `cursor: none;` 删掉，或者把字符雨的 `FONT_SIZE` 调大
